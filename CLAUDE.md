# Project Guidelines

## Git & GitHub Workflow

After completing any meaningful unit of work, commit the changes and push to GitHub. Do not let work accumulate uncommitted.

**When to commit:**
- After adding or completing a feature
- After fixing a bug
- After any change that represents a stable, working state
- Before switching to a different task

**Commit message rules:**
- Use the imperative mood: "Add login form", not "Added login form"
- First line: short summary, 50 characters or fewer
- Be specific about what changed and why, not just that something changed
- No filler phrases like "misc changes" or "update stuff"

**Push rule:** Every commit should be pushed to GitHub promptly so no work exists only on the local machine.
